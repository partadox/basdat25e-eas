Pilih Format Ujian

Pilih salah satu format ujian yang tersedia di bawah ini:

Format Original

Semua soal dalam satu halaman

  • Lembar jawaban lengkap
  • Scroll untuk navigasi
  • Auto-save setiap 30 detik
  • Format text biasa
  • Interface tradisional

Format JSON

Satu soal per halaman

  • Navigasi antar soal
  • Progress bar visual
  • JSON format answers
  • Debug mode tersedia
  • Modern interface

Status Perbaikan

✅ Bug DateTime Fixed: Timezone Asia/Jakarta telah diset dengan benar

✅ Real-time Clock: Jam real-time ditampilkan di semua halaman

✅ JSON Format: Sistem satu soal per halaman dengan format JSON telah tersedia
